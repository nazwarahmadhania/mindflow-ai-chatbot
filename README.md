# 🌿 MindFlow AI

**Your Digital Wellbeing & Productivity Assistant**

**MindFlow AI** is an AI-powered chatbot designed to help users improve productivity while maintaining a healthy work-life balance. The chatbot uses Google Gemini AI to provide personalized assistance in planning tasks, organizing study schedules, and supporting users' wellbeing through natural language conversations.

---

## ✨ Features

- 📅 Plan daily schedules
- 📋 Break large tasks into smaller, manageable steps
- 📚 Study coaching and learning strategies
- 🌱 Wellbeing check and productivity support
- 🖼️ Analyze uploaded images and documents
- 🌐 Supports Indonesian and English
- 💬 Natural language conversations powered by Google Gemini AI

## 🚀 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/nazwarahmadhania/mindflow-ai-chatbot.git
   ```

2. **Navigate to the project folder**
   ```bash
   cd mindflow-ai-chatbot
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```
   
4. **Set up Environment Variables**
   Buat file bernama .env di root folder project, lalu masukkan API Key Gemini Anda:

   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

5. **Run the application**
   ```bash
   npm start
   ```
   (atau bisa juga dengan node index.js)

6. **Open your browser**
   ```text
   http://localhost:3000
   ```
